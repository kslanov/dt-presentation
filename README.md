# Цифровой двойник: ДНК

Интерактивная презентация о том, как устроен персональный цифровой двойник - локальная система, которая помнит твою историю, пишет твоим стилем, не выдумывает факты и ведет твою операционку.

**Смотреть:** https://kslanov.github.io/dt-presentation/

Один самодостаточный HTML-файл: открывается офлайн, работает без сети, ничего никуда не отправляет.

33 главы в четырех актах - от «зачем это» через «как с ним живут» (включая личный контур) и инженерную анатомию до «твой двойник»: наставник, установка изнутри, кит. Тумблер «Подробно» добавляет глубину в любой главе, кнопки «Пример» показывают, как это выглядит у автора.

Редакция v3 (2026-11-02) по ТЗ `dt-installer/TZ-presentation-v3.md`; собрана в Claude Design.
