# Цифровой двойник: ДНК

Интерактивная презентация о том, как устроен персональный цифровой двойник — локальная система, которая помнит твою историю, пишет твоим стилем, не выдумывает факты и ведёт твою операционку.

**Смотреть:** https://kslanov.github.io/dt-presentation/

Один самодостаточный HTML-файл: открывается офлайн, работает без сети, ничего никуда не отправляет.

25 глав в четырёх актах — от «зачем это» через «как с ним живут» и техническую анатомию до «как завести своего». Тумблер «Подробно» добавляет глубину в любой главе, кнопки «Пример» показывают, как это выглядит у автора.
