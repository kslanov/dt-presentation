# Цифровой двойник: ДНК

Интерактивная презентация о том, как устроен персональный цифровой двойник - локальная система, которая помнит твою историю, пишет твоим стилем, не выдумывает факты и ведет твою операционку.

**Смотреть:** https://kslanov.github.io/dt-presentation/

Один самодостаточный HTML-файл: открывается офлайн, работает без сети, ничего никуда не отправляет.

33 главы в четырех актах - от «зачем это» через «как с ним живут» (включая личный контур) и инженерную анатомию до «твой двойник»: наставник, установка изнутри, кит. Тумблер «Подробно» добавляет глубину в любой главе, кнопки «Пример» показывают, как это выглядит у автора.

Редакция v3 (2026-11-02) по ТЗ `dt-installer/TZ-presentation-v3.md`; собрана в Claude Design.


**Установочный комплект r5** с настройкой ядра, продолжением настройки в новом
чате и опциональным Сном через Cursor. Откройте распакованную папку и напишите
«поставь» или начните с INSTALL.md из архива.

### Проверка r4 перед публикацией

20 ноября 2026 года установили опубликованный архив в чистой виртуальной
macOS 26.6.2 на Apple Silicon. Сверили SHA-256, загрузили зависимости и обе
модели поиска. Проверка установки показала 10 из 10 шагов, включая запуск
четырёх фоновых служб. Диагностика завершилась без критических ошибок.

На вымышленном документе проверили импорт, поиск, чтение первоисточника
и сохранение результата через ДТ. Распаковали резервную копию и проверили
целостность SQLite. В этой репетиции проверяли ядро. Почта, CRM, захваты
и Сон были выключены.

Загрузка Command Line Tools в виртуальной машине завершилась ошибкой TLS.
Для репетиции использовали копию уже установленных инструментов Apple с
проверенной подписью исполняемого файла Git.
